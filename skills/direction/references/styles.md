# Style families

Pick one. Each line: what it is, where it fits, the key moves, the trap.

| Family | Fits | Key moves | Trap |
|---|---|---|---|
| Swiss precision | B2B SaaS, CRM, fintech, dev tools | strict grid, one grotesk, big type contrast, hairline dividers, almost no shadow, one accent | sterile; add one warm detail |
| Soft premium | wellness, beauty, consumer apps, high-end services | generous space, large radii (16-28px), layered tinted shadows, muted palette, subtle glass on overlays only | blur everywhere, low contrast |
| Editorial | agencies, publications, studios, law, architecture | display serif or high-contrast sans, asymmetric columns, big images, pull quotes, wide margins | broadsheet cliché: rules + zero radius + columns by reflex |
| Workwear / utilitarian | trades, field service, logistics, manufacturing | condensed or wide grotesk, strong ink, hi-vis accent, labels as real data, sturdy 2-6px radius, photos of real work | army-surplus costume; keep it clean |
| Warm local | restaurants, home services, clinics, local shops | friendly humanist sans or soft serif, warm neutrals, real photos of people and place, rounded shapes, map and hours up top | stock photos, clip-art icons |
| Bento product | product launches, AI tools, feature-rich SaaS | asymmetric tile grid with real UI inside each tile, varied tile sizes, one hero tile | identical tiles with icons and two lines of text |
| Dark technical | dev tools, security, data, audio | true dark surfaces in 3 steps, one luminous accent, mono only for real code/data, crisp 1px borders | black + acid green by default |
| Brutalist / raw | portfolios, art, fashion, music | system or grotesk type at extreme sizes, visible grid, hard edges, flat colour blocks, no shadows | unreadable; keep body text normal |
| Playful / toy | kids, games, casual consumer, community | chunky rounded type, saturated 3-4 colour set, thick outlines, bouncy springs, illustrated characters | everything bounces; keep UI controls calm |
| Retro arcade | browser games, game studios, events | pixel or condensed display, CRT/scanline only as accent, neon on deep colour, hard drop shadows | fake nostalgia overload |
| Luxury minimal | real estate, jewellery, hospitality, finance for the wealthy | huge whitespace, thin serif or wide sans, black/white/one metal tone, slow fades, large imagery | empty and slow; keep CTAs findable |
| Data dense | analytics, trading, ops consoles, CRM power views | 13-14px UI, tabular numbers, compact rows (32-40px), muted chrome, colour only for meaning, keyboard-first | everything grey; status colours must pop |

## Product type to family (starting points, not rules)

- CRM / field service / back office: Swiss precision or Workwear; Data dense for list and pipeline views.
- SaaS landing: Bento product, Swiss precision, or Editorial for brand-led companies.
- Local business site: Warm local; Editorial for premium trades (architects, remodelers).
- Agency / portfolio: Editorial or Brutalist.
- Ecommerce: Soft premium or Luxury minimal; Playful for kids/novelty.
- Browser game: Playful or Retro arcade for menus; HUD always readable first.
- Fintech / health: Swiss precision with a warmer accent; never playful on money or diagnosis screens.
